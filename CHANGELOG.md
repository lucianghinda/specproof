## [0.1.0] - 2026-10-08

- First public proof-of-concept release. The public API, specification DSL, and report formats may change, including breaking changes.
- Declare bounded integer and finite input domains; check partition gaps, overlaps, and incompatible constraints.
- Plan boundary candidates and feasible pairwise combinations, with deterministic suggestions for missing pairs.
- Observe supported method calls during Minitest runs and produce human-readable and JSON coverage reports.
- Support string and Ruby method-object targets, including class/module methods, plus optional RBS input declarations.
- Include agent skills for writing specifications and reviewing test gaps.
